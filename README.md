# Téchne Website 🚀

Website institucional da Téchne - Tecnologia e Inovação

## 📁 Estrutura
```
techneNewsite/
├── css/
│   ├── colors.css      # Variáveis de cores
│   └── styles.css      # Todos os estilos (consolidado)
├── js/
│   ├── component.js    # Carrega header/footer
│   ├── script.js       # Funcionalidades principais
│   └── servicos.js     # Lógica de tabs e planos
├── pages/              # Páginas internas
│   ├── pilot.html      # Plataforma Pilot
│   ├── suporte-ti.html # Suporte Técnico
│   ├── sobre.html      # Sobre a empresa
│   └── cases.html      # Cases de sucesso
├── headerFooter/       # Componentes compartilhados
│   ├── header.html
│   └── footer.html
└── media/              # Imagens e assets
```

## 🎨 Sistema de Cores
Todas as cores estão centralizadas em `css/colors.css`:
- **Primária:** Magenta tech (#E91E8C)
- **Secundária:** Blue (#3B82F6)
- **Backgrounds:** Dark navy (#0A0E27, #141B3D, #1E2749)

## 🚀 Como Executar Localmente
```bash
# Servir com Python
python -m http.server 8000

# Ou usar Live Server (VS Code)
# Abrir index.html com "Go Live"
```

Acesse: `http://localhost:8000`

## 📝 Tecnologias
- HTML5 semântico
- CSS3 com Custom Properties
- JavaScript Vanilla (ES6)
- Google Analytics integrado
